# Task 2 — Сборка split-tunnel профиля

**Files:** `win/crates/core/src/net.rs` (новый), `win/crates/core/src/lib.rs`, `win/crates/winnet/src/ovpn_profile.rs` (новый), `win/crates/winnet/src/lib.rs`

**Produces:**
```rust
// core::net
pub struct Ipv4Net { pub addr: Ipv4Addr, pub prefix: u8 }
pub fn mask_of(bits: u8) -> Ipv4Addr
impl FromStr for Ipv4Net   // "10.0.0.0/8"
impl Display for Ipv4Net

// winnet::ovpn_profile
pub fn build_profile(source: &str, routes: &[Ipv4Net]) -> String
```

## Решения контроллера, обязательные к исполнению

**`Ipv4Net` живёт в `proxypilot-core`, не в `winnet`.** Потребителей у него четыре в трёх крейтах; тип платформенно-нейтрален. `core` обязан остаться без зависимостей от Windows — новый модуль их не добавляет.

**Функции `default_routes(office_networks)` в этой задаче НЕТ.** В плане она несостоятельна: `OfficeNetwork` в конфиге хранит GUID сети NLM, а из GUID маршрут не выводится. Офисные подсети — отдельные данные, и поле конфига под них добавляет задача 5. `build_profile` берёт маршруты параметром и конфиг не читает.

## Что делаем с исходным профилем и почему

- **`pull-filter ignore "redirect-gateway"`** — сервер обычно пушит маршрут по умолчанию и **не** пушит маршруты в офисные подсети. Без этой строки в туннель уходит весь трафик, включая видео, кругом через офис.
- **Явные `route` в офисные сети.** Подсеть, где машина стоит физически, не страдает: её собственная запись в таблице маршрутов точнее любого `/16`.
- **Пушенный DNS принимаем** — осознанное расхождение с macOS-версией (спека 8.2). Назначение туннеля здесь — внутренний git и dev-серверы, то есть внутренние имена; без офисного DNS они не резолвятся и функция теряет смысл. Плата: пока туннель поднят, все DNS-запросы идут в офис. Записать это комментарием и показать в UI (задача 7). **Не добавлять `pull-filter ignore "dhcp-option DNS"`.**
- **Вычистить `setenv opt block-outside-dns`** — директива для Windows-сборок другого клиента, наша ругается на неё при каждом старте.
- **Исходные строки не теряются.** Мы дописываем и вычищаем одну известную директиву, а не пересобираем профиль с нуля: там сертификаты и параметры, которых мы не понимаем.

## Маска

**Считается арифметикой из длины префикса, а не таблицей.** На macOS здесь был целый класс ошибок: `/14` молча превращался в `/24`. Граничные значения обязательны в тестах.
