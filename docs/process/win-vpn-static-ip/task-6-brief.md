# Task 6 — Служба профиля сети

**Files:** `win/crates/netsvc/` (новый крейт-бинарь), `win/Cargo.toml` (члены workspace), `win/crates/app/src/main.rs` (команды `install-service` / `uninstall-service`)

**Produces:** служба Windows `ProxyPilotNetProfile`.

## Почему это отдельная служба, а не код в приложении

Смена IPv4 в Windows доступна только администратору. **Ядро приложения обязано остаться без единого запроса UAC** — это свойство, за которое держались все три предыдущих плана и единственная причина, по которой инструмент можно просто дать коллеге. Поэтому статика живёт в отдельной службе, которая ставится **один раз, с одним запросом UAC, и только если статика вообще нужна**. Кому не нужна — тот не видит ни одного диалога.

## Почему служба читает свою копию профиля

`%ProgramData%\ProxyPilot\profile.toml`, которую пишет приложение — **не пользовательский файл**. Служба работает от LocalSystem; читать файл из профиля пользователя, который сам пользователь и правит, от системной учётной записи — значит открыть дорогу к подмене: кто угодно с доступом к файлу диктует системной службе, какие сетевые настройки применить.

## Что делает

- Работает от LocalSystem, подписывается на смену сети (тот же NLM, что в `winnet`), применяет решение из задачи 5.
- Применение — `netsh interface ipv4 set address` / `set dnsservers` на адаптере **офисного подключения, взятом из NLM**, а не по имени сервиса. Док-станции и вторая сетевая карта перестают быть проблемой; на macOS адаптер задавался строкой, и это было хуже.
- **Страховка:** после применения статики проверить достижимость шлюза и при неудаче откатиться в DHCP с записью в лог. На Windows риск ниже (сеть опознана по GUID, а не по совпадению префикса), но откат стоит дёшево.

## Чего ты НЕ делаешь — решение контроллера

**Не устанавливаешь службу. Не запускаешь `netsh interface ipv4 set address` и `set dnsservers` на этой машине ни в какой форме.**

Мы работаем внутри сессии на этой самой машине. Потерянный адрес рвёт связь, и откатить будет некому — а вся страховка живёт ровно в том коде, который в этот момент проверяется впервые. Регистрация службы вдобавок требует UAC, а это единственный запрос прав во всём продукте, и он принадлежит человеку.

Тесты — на разбор конфигурации службы и на **формирование** строк команд, без их исполнения. `netsh ... show` (только чтение) допустим, если нужен для разбора вывода.

В отчёте перечисли, что человек проверяет руками, и подчеркни: первый живой прогон — при пользователе и в офисной сети, а не в фоне.
