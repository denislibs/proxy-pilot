# Task 1 — Поиск установленного OpenVPN

**Files:** `win/crates/winnet/src/openvpn.rs` (новый), `win/crates/winnet/src/lib.rs` (дописать модуль по алфавиту)

**Produces:**
```rust
pub struct Installation { pub gui_exe: PathBuf, pub config_dir: PathBuf }
pub fn find_installation() -> Result<Option<Installation>, WinNetError>
```

## Что делать

Искать через реестр `HKLM\SOFTWARE\OpenVPN`: путь к каталогу установки и к каталогу конфигураций. Запасной вариант — стандартные пути установки (`%ProgramFiles%\OpenVPN`), если ключа нет, а каталог есть.

## Почему именно так

**Отсутствие OpenVPN — это `Ok(None)`, а не ошибка.** У половины получателей его не будет; падение на этом означало бы, что приложение не запускается у людей, которым туннель вообще не нужен. Раздел туннеля в UI просто станет неактивным.

**Проверять существование файлов, а не только записей реестра.** Удалённая установка оставляет ключи; `Installation`, указывающий на несуществующий exe, приведёт к невнятной ошибке при первой попытке подключения вместо честного «не установлен».

## Ограничения

- `HKLM` читается, а не пишется — чтения не требуют прав администратора. **Ни одной записи в HKLM.**
- Переиспользуй `RegKey` из `sysproxy.rs`, если он подходит; если нет — объясни почему.
- Каждый `unsafe` с `// SAFETY:`.
- Комментарии по-русски, объясняют «почему».
