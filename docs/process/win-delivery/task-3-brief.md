# Task 3 — Обновления

## Блокер снят

Источник обновлений: **`https://github.com/denislibs/proxy-pilot`** — репозиторий
партнёра, в который опубликована эта работа. Обновления тянутся только оттуда.

Почему это вообще было блокером. Работа начиналась в клоне
`jamber751/proxy-pilot` — чужого репозитория. Обновление, тянущее `.exe` из
репозитория, которым человек не владеет, есть канал доставки чужого кода прямо
в процесс, который правит ключи прокси в реестре и держит слушающий сокет.
Это не недочёт дизайна, а дыра в цепочке поставки по построению. Условие снято
тем, что появился репозиторий под контролем партнёра, а не тем, что риск
передумали считать риском: **источник обязан оставаться репозиторием, который
контролирует владелец продукта.**

## Обязательные свойства

- **Проверка не блокирует запуск** и не мешает работе: сеть может быть недоступна ровно тогда, когда прокси и нужен.
- **Скачанный файл проверяется подписью перед заменой.** При отсутствии подписи или неверной подписи обновление **не устанавливается** — не «устанавливается без проверки» и не «молча пропускается». Отключаемая проверка равна её отсутствию: отключённой она и окажется в тот единственный раз, когда важна.
- **Замена при следующем запуске, а не под работающим процессом.** Windows держит файл запущенного exe; подмена под собой процесса, который на выходе восстанавливает системный прокси, оставила бы реестр указывающим на мёртвый слушатель.
- **Пользователь может выключить проверку** обновлений (не проверку подписи).
- Дифференциальных обновлений не делаем — неоправданная сложность для инструмента такого размера.
